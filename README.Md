# Azure Data Factory Project

An end-to-end data engineering pipeline built with Azure Data Factory (ADF) that ingests hybrid multi-source data (REST APIs, On-Premises SQL Server, and Azure SQL Database), orchestrates raw-to-refined data movement across a Medallion Architecture (Bronze, Silver, Gold) in Azure Data Lake Storage Gen2 (ADLS Gen2), and produces curated aggregation models for downstream analytics and BI reporting.
